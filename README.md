# Computer Networks Laboratory

A collection of Computer Networks Laboratory experiments completed as part of the B.Tech Computer Science and Engineering curriculum at **National Institute of Technology Delhi (NIT Delhi)**.

This repository contains practical implementations, network topologies, configurations, and documentation created using **Cisco Packet Tracer**.

---

## Experiments

| No. | Experiment Title |
|:---:|---|
| 01 | Network Cables |
| 02 | Basic Network Commands |
| 03 | Study of Network Devices |
| 04 | IPv4 and IPv6 Addressing |
| 05 | Local Area Network (LAN) |
| 06 | Router Configuration |
| 07 | Network Configuration Using Switch and Router |
| 08 | Network Address Translation (NAT) |
| 09 | Routing Protocols (RIP, OSPF and EIGRP) |
| 10 | Client-Server Applications Using TCP and UDP |
| 11 | Socket-Based Client-Server Communication Using TCP (Telnet) |
| 12 | Network Simulation, Emulation, Monitoring and Management Tools |
| 13 | DHCP Server Configuration |

---

## Tools and Technologies

- **Cisco Packet Tracer** – Network design, simulation and configuration.
- **TCP/IP** – Core networking protocols.
- **Routing Protocols** – RIP, OSPF and EIGRP.
- **Network Services** – DHCP, DNS and NAT.
- **Network Analysis** – Packet inspection and simulation.

## Learning Objectives

Through these experiments, the following concepts were explored:

- Understanding network devices and topologies.
- Configuring IPv4 and IPv6 addressing.
- Implementing LANs and inter-network communication.
- Configuring routers and routing protocols.
- Understanding TCP and UDP communication.
- Implementing NAT and DHCP services.
- Exploring network simulation and packet analysis.
- Understanding network management and security concepts.
